개인정보처리방침

시행일: 2026-10-06

Hermes Google(이하 "앱")은 운영자 본인 한 명만 사용하는 개인 자동화 도구입니다.

수집·이용하는 정보

  • Gmail 메일 제목·보낸 사람·본문: 협업 메일 여부 판단과 본인 Slack 알림에만 사용
  • YouTube 댓글·영상 정보: 본인 Google 시트 정리, 본인이 승인한 답글 게시, 영상 업로드에만 사용
  • Google Drive·Sheets 파일: 업로드할 영상과 관리 시트 읽기·쓰기에만 사용

보관과 공유

  • OAuth 토큰과 처리 결과는 운영자 본인의 서버에만 저장합니다.
  • 데이터를 판매하거나 광고에 쓰거나 제3자에게 넘기지 않습니다. 단, 내용 판단을 위해 운영자가 쓰는 AI 모델 제공자에 요청 내용이 전송될 수 있습니다.
  • Google API에서 받은 정보의 사용은 Google API Services User Data Policy(Limited Use 요건 포함)를 따릅니다.

권한 철회

Google 계정 → 타사 액세스에서 언제든 앱 권한을 삭제할 수 있습니다.
